CSV format

The header row must use these column names:

{{ columns|join:"," }}

  • name (required) — product name; SKU and slug are generated from it.
  • category (required) — matched case-insensitively, and created if new.
  • description — free text.
  • cost_price — internal cost, e.g. 45.00.
  • stock_quantity — whole number.
  • is_exclusive — true/false, 1/0, or yes/no.
  • specifications — JSON object, e.g. {"Pack size": "25kg"}.
