CSV File Format

Upload a CSV file with the following columns:

name,category,description,cost_price,stock_quantity,is_exclusive,specifications
  • name (required): Product name
  • category (required): Category name (must exist in the system)
  • description: Product description
  • cost_price: Internal cost (number)
  • stock_quantity: Stock quantity (number)
  • is_exclusive: true/false, 1/0, or yes/no
  • specifications: JSON object (optional) e.g., {"Pack size": "25kg"}

Example CSV

name,category,description,cost_price,stock_quantity,is_exclusive,specifications
Long Grain White Rice 25kg,Grains,Premium imported long grain rice,45.00,100,false,"{""Pack size"": ""25kg sack""}"
Coconut Oil 1L,Oils,Pure virgin coconut oil,12.50,50,true,"{""Size"": ""1 liter""}"
